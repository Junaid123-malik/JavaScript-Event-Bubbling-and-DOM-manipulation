# Event Bubbling Practice (JavaScript DOM Project)

## 📌 Overview
This project demonstrates JavaScript event bubbling, event propagation control, and dynamic DOM manipulation using a simple nested HTML structure.

## 🚀 Features
- Demonstrates event bubbling across nested elements  
- Uses stopPropagation() to control event flow  
- Interactive alerts for each DOM level (child, child container, parent container)  
- Dynamic background color changes using setInterval()  
- Random RGB color generator function  

## 🧠 Key Concepts Practiced
- DOM event handling  
- Event bubbling vs capturing  
- event.stopPropagation()  
- setInterval() for real-time UI updates  
- JavaScript random color generation  

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript (Vanilla)  

## 🎯 Learning Outcome
This project helped me understand how browser events propagate through nested elements and how to control them effectively for building interactive UIs.
